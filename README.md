## 🎨 Design System & Visual Architecture

### 1. Japanese Sumi-e Ink Smoke & Inset Architectural Framing
The navigation header (`InkFrameHeader.tsx`) features a bespoke design inspired by traditional Japanese **Sumi-e ink plume smoke** and modernist blueprint framing:
- **Architectural Corner Framing**: Precision Drafting Corner Ticks with hairline border insets (`#ffffff0d` and `#ff4f0033`).
- **Organic Smoke Layering**: Soft ink billows and radial amber gradients that elevate the header without disrupting content readability.
- **Tactile Nav Pills**: Fluid route transitions between *Dashboard, Invoices, Clients, Services, and Settings* with amber active state halos.
- **Mobile Responsive Drawer**: Auto-collapsing slide-out drawer on viewports `< 768px` maintaining the complete luxury aesthetic.

### 2. CreepyButton Micro-Interactions (VengeanceUI)
Integrated directly via VengeanceUI, `CreepyButton.tsx` introduces an engaging micro-interaction across all primary call-to-actions:
- **Real-Time Cursor Tracking**: Trigonometric vector calculation `Math.atan2(dy, dx)` drives animated pupil displacement toward the user's cursor.
- **Physics-Damped Eyelids & Blink Cycles**: Smooth SVG eyelid rendering with CSS spring motion.
- **Spring Tilting Faceplate**: Hovering over the button activates an animated sliding faceplate revealing the lifelike eyes beneath.

### 3. Vortex 3D Simplex-Noise Canvas
Featured on the Clients showcase view, `Vortex.tsx` renders a high-performance 3D particle vortex powered by `simplex-noise`:
- **700 Active Flow Particles**: Computed across 3D noise coordinates with individual speed, TTL (Time-To-Live), and hue shifts.
- **Additive Glow Pass**: Dual-pass canvas rendering with brightness bloom for visual depth.
- **Non-blocking Interaction**: Engineered with `pointer-events-none` so all tables, cards, and modal forms retain instantaneous click responsiveness.

## 🔐 Google OAuth 2.0 Authentication

NoirInvoice includes real, production-ready **Google Sign-In** powered by `@react-oauth/google` and Google Identity Services:

```typescript
// Google Identity Services OAuth 2.0 configuration
export const GOOGLE_CLIENT_ID =
  "981402426889-d6gu6tt3sbphcdpkurj9qdmk8buuiadn.apps.googleusercontent.com";
```

### Authentication Flow:
1. **One-Tap & Standard Popup**: Users click the top-right Google Sign-In button or trigger the prompt.
2. **JWT Credential Parsing**: The Google ID token is securely decoded on the client, extracting:
   - Full Name
   - Email address
   - High-resolution Google profile avatar picture
   - Unique user subject identifier (`sub`)
3. **Persistent Session**: Cached in browser `localStorage` under `noir_auth_user` so authentication persists seamlessly across page reloads and browser restarts.
4. **Header Profile Display**: Once authenticated, the header immediately displays the user's Google avatar, name, and an interactive dropdown with 1-click Sign Out.

## ⚡ Core Capabilities

### 🤖 AI-Powered Scope & Invoice Generation
- Integrates Google Gemini AI (`@google/genai`) to generate comprehensive, professional project invoices from natural language prompts.
- Describe a project (e.g., *"Full-stack SaaS MVP with Next.js, Stripe integration, and 2 revision rounds"*), and Gemini automatically generates itemized deliverables, realistic hourly rates, tax brackets, and payment milestones.

### 📱 Scan-to-Pay Dynamic UPI QR Engine
- Generates dynamic, real-time UPI QR codes using `qrcode.react` based on the active invoice total and configured VPA/UPI ID.
- Fully compatible with all major UPI payment apps: **Google Pay, PhonePe, Paytm, BHIM, Cred, and Navi**.
- Encodes the standard UPI protocol URI:
  ```text
  upi://pay?pa=recipient@upi&pn=BusinessName&am=12500.00&cu=INR&tn=Invoice%20INV-2026-001
  ```

### 📄 Pixel-Perfect Client-Side PDF Export
- Compiles pristine, print-ready PDF documents directly in the client using `html2pdf.js` with zero server rendering lag.
- Preserves exact typography, tabular spacing, custom brand logos, and status stamps.
- Native `react-to-print` support for direct physical printouts or browser PDF spooling.

### 💱 Multi-Currency Ledger & Instant Recalculation
- Seamlessly toggle between major international currencies:
  - **INR (₹)** — Indian Rupee
  - **USD ($)** — US Dollar
  - **EUR (€)** — Euro
  - **GBP (£)** — British Pound
  - **AED (د.إ)** — UAE Dirham
- Instant recalculation of line totals, subtotal, configurable GST/VAT rates, custom discounts, and shipping charges.

### 🗂️ Persistent Client & Service Catalogs
- Built-in directory management for clients and recurring service templates.
- Saved clients appear instantly across all invoice creation dropdowns and invoice history.
- Browser storage persistence ensures client records and saved invoices remain accessible offline and across sessions.

## 🚀 Quick Start & Installation

### Prerequisites
- [Node.js](https://nodejs.org/) `>= 18.0.0`
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/) or [bun](https://bun.sh/)

### 1. Clone the Repository
```bash
git clone https://github.com/juzer09jawadwala-source/invoice-generator-.git
cd invoice-generator-
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Setup Environment Variables
Create a `.env.local` file in the project root:
```bash
cp .env.example .env.local
```

Populate the keys:
```env
# Google Gemini AI (Optional - enables AI invoice drafting)
GEMINI_API_KEY=your_gemini_api_key_here

# Google OAuth Client ID (Pre-configured for NoirInvoice)
VITE_GOOGLE_CLIENT_ID=981402426889-d6gu6tt3sbphcdpkurj9qdmk8buuiadn.apps.googleusercontent.com
```

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Build for Production
```bash
npm run build
npm run preview
```
